# Malermeister Jörg Heller — Designentwurf

Designentwurf für eine Website des Maler- und Lackierermeisters Jörg Heller,
Wilhelmstraße 10, 17309 Pasewalk. Der Betrieb hat bisher keine eigene Website.

## Inhalt des Entwurfs

- **Logo:** das bestehende Logo des Betriebs (Gelbe Seiten), originalgetreu als Vektorgrafik nachgezeichnet
  (`tools/logo.py`): Wahlspruch „Kunst bringt Gunst“, Zunftwappen der Maler, Name in Fraktur.
  Die Farben der Seite (Weinrot, Terrakotta, Creme) stammen aus diesem Logo.
- **Kopfzeile** mit Infoleiste (Einzugsgebiet, E-Mail, Telefon) und Navigationsleiste
- **Hero:** Text links, hohes Foto bis zum rechten Rand, daneben eine Farbmusterkarte mit
  Google-Bewertung (5,0, 2 Rezensionen), Meisterbetrieb, Gewerken und Standort
- **Leistungen** als Farbkarten: Maler-, Lackier-, Tapezier-, Putz- und Stuckarbeiten
- **Ablauf** in vier Schritten, **Über uns** („Kunst bringt Gunst“), Anruf-Band, **Häufige Fragen**
- **Kontakt** mit Anfrageformular (eigene Auswahllisten und Checkbox, Versand im Entwurf simuliert)
- **Gestalten:** ein Werkzeug im Browser (Knopf unten rechts) zum Ausprobieren von Farben
  (Farbkreis, Vorlagen, Harmonien, Kontrastprüfung) und Schriften. Es wird vor der Übergabe entfernt.
